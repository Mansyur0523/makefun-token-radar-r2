Which pre-token protocol is worth farming next?

Every protocol below records no token in the snapshot. Each is ranked by an implied value fitted from the traded tokens in the same snapshot — not from a hand-picked list of names — and each carries a concrete farm plan netted to dollars.

How the value is fitted — and how it was tested blind

The curve is an OLS regression on the snapshot’s own traded tokens (protocols with a positive market cap and a positive TVL):

log(mcap) = a + b × log(TVL) + offset[category]

Implied value = exp(prediction) × P(launch), where P(launch) is a stated function of TVL size, 7-day TVL growth and days listed with no token. A protocol’s token is recorded as absent in the snapshot — never claimed to not exist.

Blind validation

The band is wide: TVL explains only part of a market cap. The board ranks by the central estimate and shows the 90% band on every row, so a reader can see how rough the number is before farming it.

Launch odds & farm maths

P(launch) = clamp((0.10 + 0.55 × size) × growth × maturity, 0.05, 0.80). Size runs 0–1 over log10(TVL) $5M–$10B. Growth is 1 + clamped 7-day change ÷ 200. Maturity is 0.75–1.00 over 0–3 years listed with no token.

Expected value to one active farmer = implied value × 0.01% − farm cost (gas for 7 transactions + 5% a year on locked capital). Verdict: farm at $250 or more, thin at $0 or more, skip below $0. The 0.01% share is an assumption, stated here so it can be argued with.
